## Installation

### 1. Manually Integrate the SUDGI SDK

#### Download [SUDGI](https://github.com/SUD-GLOBAL/sud-gi-android/releases)

##### SDK: Android-SUDGI-v2.0.0.1301.zip

##### Unzip the ZIP package to obtain the extracted AAR file, copy the AAR file into your project, and add it as a dependency in your project.

### 2. Integrate the SUDGI SDK via Maven

```ruby
// To publish on Google Play, replace it with this dependency: api 'global.sud.gi:SUDGI-static:2.0.0.1301'
api 'global.sud.gi:SUDGI:2.0.0.1301'
```
